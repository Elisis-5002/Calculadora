Calculadora is a Windows Forms application built with C# on .NET 10. A main MDI-style menu opens a set of independent mini-tools, each of which demonstrates a core desktop development concept:
It's a project developed to explore Visual Studio and C#, for Topicos Avanzados de programación (University class) 
Simple calculator: addition, subtraction, multiplication and division on integers, with input validation and error dialogs.
Bubble sort: enter integers in a grid and see them sorted by a custom sorting class.
Person registry: register people (name, last name, birth date) in a tabbed form, with automatic age calculation and a data-bound grid for viewing and deleting records.
Clock and alarm: a live clock driven by a timer, with a configurable alarm that plays a sound, plus access to the stopwatch.
Stopwatch and counter: a start/stop/reset stopwatch and a counter whose speed is adjusted with a trackbar.
Text editor: open, save and save-as using file dialogs, font and color pickers, and a live word counter with a click-to-view statistics dialog.
XML directory: capture contacts in a grid and export them to an XML file using LINQ to XML.

Requirements: Windows, the .NET 10 SDK, and Visual Studio 2022 or later (open Calculadora.slnx).
